# PopDeck v0.1.8

## 中文

- 修正液态玻璃设置：移除只改变黑色着色的“玻璃浓度”滑块，改为 Apple 原生的“常规 / 清透”材质选择。
- 默认采用常规玻璃，由系统自适应模糊背景，改善明亮背景上的可读性；清透模式保留更明显的通透感与边缘折射。
- 去除自定义黑色着色，名称及符号使用语义前景色；旧系统继续使用原有毛玻璃。
- 保留快捷方式和其他偏好。旧版浓度值不再用作模糊参数；升级后默认常规玻璃。

公开 API 不提供应用内连续模糊强度参数。系统外观及辅助功能设置也会影响玻璃表现。此版本保留 0.1.7 的启动自动检查更新修复，后台检查遵循已有许可和偏好。

最低要求：macOS 14，Apple Silicon。当前版本采用临时签名，尚未进行 Developer ID 签名和 Apple 公证。

## English

- Replace the misleading Glass intensity tint slider with Apple's native Regular and Clear material styles.
- Default to Regular, which adapts background blur for readability; Clear keeps a more transparent backdrop and prominent edge refraction.
- Remove the custom black tint and use semantic foregrounds for labels and symbols. Older systems retain the existing frosted material.
- Preserve shortcuts and other preferences. The old intensity value is no longer interpreted as blur; upgraded installations default to Regular.

The public API does not expose an app-level continuous blur strength. System appearance and accessibility settings can also affect glass. Launch-time automatic checking from 0.1.7 is retained and respects consent and saved preferences.

Requires macOS 14 or later on Apple Silicon. This release uses ad-hoc signing and is not Developer ID signed or notarized.
