# PopDeck v0.1.7

## 中文

- 新增命令快捷方式：在设置中添加 Shell 命令，点击圆环图标即可后台执行；支持多行、管道及重定向，失败时显示错误。
- macOS 26 及以上采用系统原生 Liquid Glass，修复窗口焦点导致玻璃变灰的问题；旧系统保留毛玻璃。
- 新增“玻璃浓度”滑块，实时调整原生着色强度并自动保存，改善明亮背景下的可读性。
- 修复点击圆环外关闭面板时短暂闪现深色圆形的问题。
- 更新检查器现在随应用启动，不再依赖打开菜单栏菜单；保留用户的自动检查偏好。

命令以 `/bin/zsh -lc` 从用户主目录运行，不打开终端、不支持交互输入。玻璃浓度调整原生着色强度，不是系统模糊半径。

最低系统要求：macOS 14，Apple Silicon。下载 `PopDeck-0.1.7.dmg` 后，将 `PopDeck.app` 拖到“应用程序”文件夹。当前版本尚未采用 Developer ID 签名和 Apple 公证。

旧版用户可从菜单栏选择“检查更新…”。新版启动时会初始化更新器；后台检查仍遵循 Sparkle 的用户许可和偏好，不是即时推送或强制安装。

## English

- Add shell command shortcuts with multiline source, pipes and redirection; execution errors are shown.
- Use native Liquid Glass on macOS 26 and later; fix inactive-window frosting while retaining the older-system fallback.
- Add a live, saved Glass intensity slider using native tint to improve contrast on bright backgrounds.
- Prevent the dark-circle flash when dismissing the launcher by clicking outside it.
- Initialize the updater at launch so scheduling no longer depends on opening the menu bar menu; honor the user's automatic-check preferences.

Commands run via `/bin/zsh -lc` from your home directory without a terminal or interactive input. Glass intensity controls native tint, not the system blur radius.

Requires macOS 14 or later on Apple Silicon. Download `PopDeck-0.1.7.dmg` and drag `PopDeck.app` to Applications. This release is not Developer ID signed or notarized.

Existing users can choose Check for Updates from the menu bar. Background checking follows Sparkle's consent and saved preferences; updates are not pushed instantly or forcibly installed.
