# PopDeck 0.1.9

- 普通版支持在一圈中添加最多 8 个入口，打开应用、文件、文件夹、网址或执行命令。
- 命令可编辑，支持静默执行或打开终端；图标支持颜色与 Emoji，入口可选择图标、文字或图标加文字。
- 设置页采用侧栏导航，面板预览与配置同页显示；支持调整扇形宽度、面板大小、文字排布及悬停音效。
- 支持系统原生常规／清透液态玻璃；旧系统保留毛玻璃。
- 新增 PRO 多圈、分组和扇形命令集。人民币 ¥6 / US$1 / 1 USDT 一次性永久解锁，包含后续 PRO 更新，可在本人多台 Mac 使用。人工收款后发码，在设置中粘贴激活，无订阅。
- 保留已有启动项和外观偏好，沿用 Sparkle 应用内更新。公开仓库提供可独立构建的普通版源码。

## English

- Free supports up to eight launch items: apps, files, folders, websites and shell commands.
- Edit commands and run them silently or in Terminal. Customize colors, Emoji, and icon/text presentation.
- Sidebar settings keep live panel previews beside configuration. Adjust sector widths, panel size, text layout and hover sounds.
- Native Regular and Clear Liquid Glass on supported macOS, with the existing blur fallback on older systems.
- PRO adds multiple rings, groups and sector command sets. Pay CNY ¥6 / US$1 / 1 USDT once for a personal lifetime license, including future PRO updates, on your own Macs. Manual payment verification and offline code activation; no subscription.
- Existing launcher items and appearance preferences are preserved. Sparkle in-app updates continue to work. Independently buildable Free source is available publicly.

The app continues to use ad-hoc signing; Developer ID signing and notarization are not enabled. Minimum macOS 14; Apple Silicon.
