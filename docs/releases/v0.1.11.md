# PopDeck 0.1.11

- 启动项、分组和分组内项目支持选择本地图片作为自定义图标；命令集也支持自定义徽标。
- 新增恢复默认图标按钮，可随时恢复原始图标。自定义图片会随配置保存，移动或删除原图片不影响显示。
- 修复快捷键呼出面板后偶发的悬停失效：改进焦点恢复，让鼠标移入选中和棘轮音效及时响应。
- 保留现有启动项、外观偏好与 PRO 授权；实验设置继续隐藏。

## English

- Choose custom image icons for launch items, groups, group children and command-set badges.
- Restore original icons with a reset button. Imported icons are saved with your configuration and remain available after the source image moves or is deleted.
- Fix intermittent missing hover selection and ratchet sounds after invoking the panel with a shortcut by improving focus recovery.
- Existing items, appearance preferences and PRO activation are preserved. Experimental settings remain hidden.

Minimum macOS 14; Apple Silicon. This build uses ad-hoc signing. Developer ID signing and notarization are not enabled.
