# PopDeck 0.1.12

macOS 与 Windows 统一使用 0.1.12，版本信息由同一份 VERSION 管理，各自保留独立更新渠道。

- 官网新增 Windows 下载，根据访客系统选择推荐平台，并支持手动切换 macOS / Windows 与 Windows x64 / ARM64。
- Windows 保留圆环层级、圆角分组和下载、解压、安装、重启进度；安装包通过同域 HTTPS 下载。
- macOS 应用功能保持现有行为，更新发行版本为0.1.12、内部构建号13。
- 配置与授权保留。Mac 安装包继续使用现有代码签名方式及 Sparkle 更新签名。

macOS 需要 Apple Silicon 与 macOS14+；Windows 提供 x64 和 ARM64 自包含版本，支持 Windows10/11。
